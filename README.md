# ShopRU — интернет-магазин

Учебный проект интернет-магазина на Next.js 14, React 18 и Tailwind CSS. В каталоге 40 демонстрационных товаров, категории, поиск/фильтрация, избранное, корзина, профиль и оформление тестового заказа. Данные хранятся в браузере через localStorage. Реальной оплаты и backend-заказов нет.

## Запуск локально

Требуется Node.js 18.17 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Публикация

Для GitHub Pages проекту потребуется статический экспорт Next.js (настроить `output: "export"` в `next.config.js`, проверить совместимость маршрутов и пересобрать). Более простой вариант для Next.js — Vercel: импортировать репозиторий и оставить стандартные настройки сборки (`npm run build`).

## Изображения

Фотографии товаров загружаются с Unsplash по прямым ссылкам. Для стабильной офлайн-работы можно скачать их в `public/images` и заменить URL в `data/products.js` на локальные пути.

## Важно

Цены, скидки и товары демонстрационные. Проект не подключён к реальному магазину, платёжной системе или базе данных.
